# Biblioteca Mágica — Ascendio RP

Wiki pública de regras, guias, documentação e lore da comunidade Ascendio RP.

Construída com Zensical, editável pelo Pages CMS e preparada para Cloudflare Pages.

## Como executar

```bash
pip install -r requirements.txt
zensical serve
```

## Publicação na Cloudflare Pages

- Build command: `pip install -r requirements.txt && zensical build`
- Build output directory: `site`
- Root directory: `/`

## Edição de conteúdo

Entre em https://app.pagescms.org/, autorize o repositório e edite as coleções. Antes de liberar colaboradores, configure permissões e revisão no GitHub. Conteúdos confidenciais não devem ser enviados a este repositório público.
